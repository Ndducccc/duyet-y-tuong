Nạp danh mục ý tưởng

Dán bảng copy từ Excel Online, hoặc thả file .xlsx vào đây.

1 · Dán từ Excel OnlineChọn cả sheet (bấm ô góc trên trái), Ctrl+C, quay lại trang này nhấn Ctrl+V. Nhớ bỏ lọc trước khi copy.
2 · Kéo thả fileKéo file từ thư mục OneDrive đồng bộ hoặc file vừa tải về rồi thả vào khung này. Chọn được sheet theo quý.
3 · Chọn file

Ghi kết quả về Excel

Xuất file Excel mới đã điền kết quả (nhanh nhất)

  1. Tool lấy file Excel gốc, ghi kết quả vào cột S, T, U theo Mã số, giữ nguyên định dạng, rồi tải về một file mới. File gốc không bị sửa.
  2. Mở file mới kiểm tra, sau đó tải lên SharePoint hoặc chép các cột sang file chung.

Cách A · Office Script

  1. Bấm Copy script bên dưới.
  2. Trong Excel Online: tab Tự động hóa → Tập lệnh mới, xoá code mẫu, dán vào.
  3. Bấm Chạy. Script tìm từng dòng theo Mã số trên sheet rồi ghi cột S (Phê duyệt), cột T (Thưởng); cột U chỉ ghi khi có ghi chú. Định dạng file giữ nguyên.
